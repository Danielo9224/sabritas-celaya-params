# sabritas-celaya-params

Repositorio de parámetros y configuraciones para Sabritas Celaya.

## Descripción

Este repositorio contiene los parámetros y configuraciones utilizados en el proyecto Sabritas Celaya.

## Uso

Clona este repositorio para acceder a los parámetros de configuración:

```bash
git clone https://github.com/Danielo9224/sabritas-celaya-params.git
```

## Contribución

1. Haz un fork del repositorio.
2. Crea una rama para tu cambio: `git checkout -b mi-cambio`
3. Realiza tus modificaciones y haz commit: `git commit -m "Descripción del cambio"`
4. Sube tu rama: `git push origin mi-cambio`
5. Abre un Pull Request.
